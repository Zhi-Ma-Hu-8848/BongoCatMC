# BongoCatMC

独立的网易 Minecraft ModSDK 项目。内置默认小猫和 DeepSeek 桌宠，HUD 响应游戏输入。

## 当前功能

- “表情”右侧的“模型”下拉菜单可在默认小猫和 DeepSeek 之间切换，选择保存在本机。每个模型只展示自己的动作和表情；切换停止旧动作与音效。大小、镜像、鼠标回正和拖动位置沿用公共设置。
- DeepSeek 内置四个表情（碗、眼镜、便利贴、彩蛋）与四个动作（惊讶、打招呼、流汗、爱心），其中两个动作带原音效。原包有 17 张键盘手部图，保留原分辨率；不支持的按键不再错误显示成 W。

操作菜单采用浅粉背景、深粉选中态与深色文字。设置面板位于左侧按钮下方，淡粉背景为 30% 不透明度，提供大小（50%～200%）滑条及上下镜像、左右镜像、鼠标回正三个独立开关（默认关闭），实时预览并在松手或关闭时保存本机全局配置。

- 长按小猫约半秒后可拖动位置，短按打开菜单；松手保存位置，按屏幕比例适配分辨率。
- 手机拖动以当前手指回调为准；缺少移动回调时，使用按下时校准过的 `GetTouchPos()` 兜底。检测到其他手指后停用无指针编号的兜底，避免抢走拖动。按下区域在拖动期间固定，只移动角色画面，松手再更新点击区域；区域外松手也保存，页面退出则结束捕获。大小滑条共用这套坐标处理。
- 进入世界后自动显示右下角小猫（调整后使用保存的位置）；仅小猫上的点按区域接收交互，其余 HUD 不吸收游戏操作。
- 字母、数字、空格、Shift、Ctrl 等按键使用原模型配套的键盘爪贴图；箭头键映射为 WASD。
- 多键同时按下，显示最近按下且仍按住的键；松开一个键不会清除其他按键。
- 鼠标左键/右键分别显示原模型的鼠标按键效果，可与键盘同时响应。
- 转动游戏视角带动小猫和鼠标爪，停止后平滑回中；自动眨眼。
- 触屏下蹲跟随玩家的实际下蹲状态，显示 Shift；点击切换模式下松开手指仍保持，取消下蹲后松爪。不会因移动、跳跃或右键松手而清掉下蹲状态。
- F8 显示/隐藏 HUD；菜单内隐藏并清理输入。游戏暂停超过 0.75 秒后清理遗留按键。
- 按 **F** 或触屏轻点小猫打开左上角“设置、动作、表情、模型”四个并排按钮；“设置”打开外观面板，再次按 F 或点右上角“退出”返回游戏。动作、表情各有独立下拉菜单，宽度与按钮一致，统一显示三行半；第一项为“停止所有动作／表情”，选择后收起，点空白也可收起。超过可见范围使用原生滚动列表，支持鼠标滚轮与触屏拖动，拖动不触发选项。选项集中维护在 `menu_catalog.py`，不固定为两个动作或三个表情按钮。其他游戏菜单中不响应打开请求。
- 表情：默认、墨镜、光环；重复选择当前表情可取消，按原模型淡入时长平滑过渡。动作：闪电（含原配音效）、挥手；点击可重播，“停止”同时停止动作与音效。两个重复的原始动作分组只显示一次。
- 默认猫动作沿原始 Cubism 曲线播放一次后恢复输入；挥手期间暂时让原动画控制键盘爪，结束后恢复当前真实按键。表情可以与动作同时使用。关闭面板后仍在 HUD 播放。
- 接入移动端的移动、跳跃、短按、长按和松手事件。通过 `GetInputVector()` 连续读取摇杆，前后左右对应 W/S/A/D；斜向选主方向并加方向边界防抖，回中松爪。短按使用右键效果，长按使用左键效果；原生使用按钮的触屏释放也会正确清除右键状态。

## 启动

双击根目录 `启动BongoCatMC.cmd`。

启动器使用本机 `D:\MCDevTool\v1.6.1\mcdk.exe`，配置在 `.mcdev.json`。使用独立世界 `BONGOCATMC_HUD_001`、本地调试端口 `18905`，不会重置旧世界。如果已有 MC 或 MCDK 进程，会提示使用已有窗口，避免重复启动。

当前版本使用 **OpenGL GLSL**。启动器会选择 OpenGL，并将之前的渲染设置记录到 `diagnostics/launcher/`。本轮没有实现 DirectX 着色器分支。

移动端渲染面向支持网易自定义纸娃娃 GLSL 材质的 **GLES 3.x** 通路。两种模型共用高精度、显式第 0 级数值纹理读取；现代 GLSL 使用 `texelFetch`，桌面 GLSL 1.20 使用 `texture2DLod`。保留引擎多版本头、原始图像分辨率和预乘 Alpha。DeepSeek 需要支持 4096 像素纹理及顶点纹理采样；不能把图片缩小作为兼容方案。

2026-11-05 参考 Balatro 的验证流程，修复 GLES 3.1 顶点 `texture2D` 编译失败，并为颜色及数值纹理采样器显式声明 `highp`。32 组编译/链接通过；18 种真实模型姿态在四种版本下共 72 次图像对比，与修复前桌面输出最大通道误差为 0。以上使用电脑驱动，**尚未证明 Android/iOS 真机画面与性能**；不承诺 GLES 2、Metal、Vulkan、DirectX 或其他不加载该 GLSL 材质的后端。复现方式见 [移动端渲染记录](docs/mobile-rendering.md)。

## 实现

默认小猫来自 BongoCat 的 `standard` 模型。构建时通过 Cubism Core 采样数值顶点位置、透明度和遮罩坐标，游戏内使用网易纸娃娃自定义网格与着色器插值。保留原始网格、材质裁切和键盘爪的静态贴图，不生成动作图片序列帧，不在游戏内运行 Cubism Core。

原始模型 224 顶点，运行网格 264 个三角形（含背景及按键爪）。400 组输入姿态和 5125 组独立参数姿态；3 张运行纹理合计约 1.28 MiB，其中姿态数据是顶点数值，不是图片序列帧。每帧只更新改变的着色器参数，输入完全在客户端处理，无持续网络同步。

表情/动作的部件独立性在构建时与 Cubism Core 的 80 组组合参数核对，另用 40 组中间参数核对插值，墨镜的非线性运动使用更密的数值采样。闪电与挥手的时间曲线直接保留原 JSON（包括非受限贝塞尔的时间轴求逆）；原 FLAC 音效无损解码为 PCM WAV。默认猫之外的模型转换不在这套专用参数数据的支持范围。

55 张按键爪保留原始 612×354 画布内的全部可见像素，不降采样、不缩小。图集仅去除 Alpha 为零的外围空白，元数据保留原坐标，绘制时恢复原位置；图集仍为 2048×2048。图片不以包体或预估性能为由降低分辨率。

颜色图集在构建时预乘 Alpha，材质使用 `One / OneMinusSrcAlpha`，片元着色器同时对 RGB 和 Alpha 应用遮罩及部件透明度，避免按键爪与身体的白色接缝出现灰线。数值姿态和元数据纹理不预乘。贴图、材质和着色器需要配套更新。

`tools/build_cat.py` 专用于默认小猫；`tools/sample_deepseek_parameters.cjs`、`tools/build_deepseek.py` 和 `tools/build_deepseek_parameters.py` 专用于本次 DeepSeek 桌宠。这还不是通用自定义模型副包转换器。

DeepSeek 保留 4096×4096 原始材质与 17 张手部图的全部可见像素，手部图只裁透明边缘、放入未被任何原模型 UV 使用的图集空位。三张运行纹理合计约 12.12 MiB，数值数据纹理为 4096×2048；不是图像序列帧。原网格 5867 顶点，Cubism Core 6.0.1 只用于构建，游戏中使用自定义纸娃娃网格与 GLSL。

DeepSeek 使用 33 个连续参数的局部变形表和父级仿射变换，替代整段动作顶点叠加。100 组独立组合参数与原 Core 核对，最大顶点误差约为 1024 像素源画布上的 1.09 像素；这属于数值插值误差，不是图片降分辨率。运行时按原曲线计算表情、动作、随机眨眼和五组呼吸信号，六组物理（前发、后发、眼睛、双耳、呆毛、尾巴）使用 120 Hz 固定子步和帧间插值。Python 只处理参数及 15 个物理粒子，顶点变形在 GPU 完成；不会逐顶点调用 ModSDK。

动作语义对照 BongoCat v1.14.0：惊讶播放一次后恢复；打招呼、流汗、爱心保留末尾状态，再点同项取消。控制不同参数组的动作可共存；表情切换和停止都有淡入淡出。除打招呼占用左手外，动作期间仍响应键盘和鼠标。菜单中跟随光标，游玩时跟随视角输入。默认小猫保留其原有动作规则。

DeepSeek 重新构建：`npm install` → `npm run sample:deepseek` → `python tools/build_deepseek.py`（也可 `npm run build:deepseek`）。构建器先生成原分辨率图集、音效和注册数据，再生成与当前着色器配套的参数表；不会输出旧版整段动作采样格式。`tools/sample_deepseek.ts` 仅保留为早期研究记录，不用于当前运行资源构建。默认模型构建会保留其他已注册模型、材质和音效。

物理参考数据保存在 `tools/fixtures/`；需要重新对照官方 Framework 时运行 `npm run reference:deepseek`。`python tools/test_deepseek.py` 不依赖本地临时诊断文件。更新 GLSL 后，MC 的世界重载可能沿用旧材质缓存，应重启游戏进程使着色器更新。

## 构建与检查

依赖 Node.js、Python 3、NumPy、Pillow、SoundFile。游戏脚本兼容 Python 2.7。

```powershell
node tools/sample_cat.cjs
& 'C:\Users\CJK\AppData\Local\Programs\Python\Python313\python.exe' tools/build_cat.py
& 'C:\Users\CJK\AppData\Local\Programs\Python\Python313\python.exe' tools/test_input.py
& 'C:\Users\CJK\AppData\Local\Programs\Python\Python313\python.exe' tools/test_effects.py
& 'C:\Users\CJK\AppData\Local\Programs\Python\Python313\python.exe' tools/test_hud_startup.py
```

MCDK 正在运行时，`tools/check_runtime.py` 只读取运行状态及截图；`tools/verify_runtime.py` 在后台注入模组回调验证 HUD，不发送操作系统键鼠输入，不改变世界。后者只应在没有同时游玩时运行，结束后恢复原输入对象。

基础 HUD 曾通过 10 项 MC 后台回调到渲染检查。表情/动作系统完成离线行为回归、输入回归、原图像素校验与 ModSDK 代码检查；下拉菜单在现有 MC 中后台重载、检查截图与回调，未发送操作系统键鼠输入。**手机实机滚动手感仍待验收。** 当前只监听游戏内输入，不监听 Windows 桌面其他应用。
