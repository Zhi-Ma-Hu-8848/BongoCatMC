# MC 输入与验收

参考实现：BongoCatMC `addon/behavior_pack/bongocat_mod/client/pointer.py`；相关经验来自 Balatro 与 zhima。复用前先检查现有接口及调用方。

## 触摸捕获

- 当前手指的 TouchId 回调是坐标主来源。GetTouchPos 无手指身份，可能陈旧；按下时校准，仅在移动回调缺失且没有其他手指时兜底。释放不能从全局轮询取坐标。
- 合法释放坐标可用，手机 `(0,0)` 释放通常无效；桌面部分 Move 也可能带零占位值，需要区分。
- 拖动时冻结原生捕获按钮位置，只移动视觉。松手后再移动点击区域，避免边移动边重建命中导致失去捕获。
- 长按 .45 秒、容许 12 逻辑像素抖动，提前滑动取消点开菜单。区域外松手仍结束拖动，页面退出取消捕获。
- 大小滑条共用指针逻辑，越界坐标钳制；先前原生滑条最右越界释放会跳零，因此不直接信任异常回调值。

## 游戏输入响应

触摸摇杆用 GetInputVector 判断 WASD，斜向选主方向并做边界防抖。下蹲跟随实际下蹲状态，支持切换式按钮；不能仅用触摸抬手清除。原生使用按钮的释放也要清理鼠标右键表现。视角、菜单鼠标跟随和鼠标自动回正设置分别处理。

验证区分离线状态机测试与设备测试。电脑可验证模拟回调和真实鼠标，无法证明手机多指/原生控件行为；用户已经要求不测试时，不再次启动游戏或索取前台权限。运行时如涉及资源刷新，参考 rendering.md 的 include 和缓存限制。
